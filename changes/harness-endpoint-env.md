- dispatch: a claude worker on a route with an endpoint gets that endpoint's environment (`ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN` from the route's `token_env`, every model alias set to the route model, nonessential traffic off) and loses the operator's `CLAUDE_CODE_OAUTH_TOKEN`, Bedrock/Vertex switches and `ANTHROPIC_API_KEY`. The token is never in argv and is redacted from logs. Routes without an endpoint are unchanged.
