Governor: a new `serverApprovals` setting (default off) lets a person answer an `ask` in Enforcer instead of a dialog on the machine. The PreToolUse hook ships the ask receipt, polls `GET /approvals?install=&receipt_hash=` with the ingest key for up to `serverApprovalWaitSec` (at most 20 s), verifies the signed decision (sha256, Ed25519 under the server's or a pinned key, message type, install and receipt hash) and runs the tool only on a verified approval; denied, unverifiable and unanswered asks block (`ask_approved`, `ask_denied`, `ask_unverified`, `ask_unanswered`). A retry of the same action re-checks the earlier ask, so a late approval still counts once.
