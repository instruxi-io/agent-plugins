- `enforcer dispatch` preflight now has an `acceptance` check: every open node of a dispatchable type has its acceptance lines linted by the graph's lint endpoint, and any warning (or a task/bug/chore with no acceptance lines, `acceptance_missing`) fails preflight with one `<key>: line <i> <code> — <text>` line per finding, before anything is spent. `--allow-lint-warnings` turns the failure into a warning; `enforcer plan check` takes the same flag and reports the same findings.
