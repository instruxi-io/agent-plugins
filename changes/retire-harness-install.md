`enforcer harness install|uninstall <grok|codex>` is now one manifest-driven migration off the old runtime copy and the `~/.local/bin/enforcer` shim: it removes what the old manifest lists, restores recorded `.enforcer-bak-*` files and prints the native install command (nothing is written when there is no manifest). The copier and `src/shim.mjs` are gone; `enforcer doctor` reports a leftover copy as `old runtime copy at <dir>: run enforcer harness uninstall grok`.
