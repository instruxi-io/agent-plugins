The dispatcher reads a per-tier route table (--routes, ENFORCER_ROUTES, the graph's node_defaults.routes, or <config home>/dispatch/routes.json; --no-routes ignores them): each tier gets a harness, model and optional endpoint by the precedence in docs/graph/ROUTES.md, an endpoint is probed at /v1/models (cached --route-probe-ttl, default 60 s) with a per-route fallback (wait holds the node without spending an attempt, route:<tier|harness> reroutes), a bad table or a route on an unsupported harness exits 5 at startup, and preflight and dispatch status show the routes; `enforcer dispatch` no longer passes --model sonnet when none was given, and status shows each tier's model (mechanical is sonnet, not haiku).
