- Telemetry-only ingest keys for harnesses that take a fixed OTLP header (Codex, Gemini CLI, Hermes, OpenClaw): `src/ingest-key.mjs` (`ensureIngestKey({harness})`, `ingestHeaders(harness)`, `INGEST_SCOPE`, `OTLP_BASE(baseUrl)`) and `enforcer ingest-key --harness <h> [--json]` find or create a v3 agent `<harness>@<hostname>` under the signed-in account, issue it one credential carrying `INGEST_SCOPE`, and cache it per harness in `~/.enforcer/ingest-keys.json` (0600, atomic). The key is checked with v3 at most hourly, rotated with under 7 days left (old secret keeps working 24h), minted again when revoked, and never replaced when the agent is disabled in the console (the off switch). Signed out is an error with no network call; concurrent callers share one mint through a lock beside the refresh lock. CLI exit codes: 0 ok, 1 failed, 2 usage, 3 signed out, 4 agent disabled. `INGEST_SCOPE` is the working name `enforcer:governance-ingest.write` until the v3 scope lands.
