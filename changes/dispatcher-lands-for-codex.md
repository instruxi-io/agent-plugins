The dispatcher now commits, pushes and lands for Codex workers: codex's `workspace-write` sandbox keeps a linked worktree's git metadata read-only by design, so the `--add-dir <git common dir>` workaround is dropped and a codex worker is told to edit files and run checks only, then report succeeded. After it exits, graph-dispatch commits its worktree on the card branch (message naming the node and run), pushes, opens the PR (ending `Enforcer-Run:`), lands it with land-pr.sh and posts the `github.pr_merged`, `github.checks_green` and `github.pr_untouched` runner records to the run. An empty diff, or one deleting files with zero additions outside the node's paths, is not committed and fails the run with `destructive_or_empty_diff`; red CI fails the run with the land-pr output as evidence, never merged.
